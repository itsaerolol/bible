# bible

A personal video system for short vertical reflections from reading the Bible.

Record yourself talking. Claude clarifies your point, edits the video with HyperFrames (captions with keyword emphasis, restrained graphics), and learns from every video you post. A private dashboard tracks YouTube performance.

Start with `docs/setup.md`. Decisions are in `docs/decisions.md`. The agent rules are in `CLAUDE.md`.

```
/episode          whole loop for one video
/clarify          sharpen your point before you record
/posted <url>     close the loop after posting
/evolve           apply what the last video taught
```
