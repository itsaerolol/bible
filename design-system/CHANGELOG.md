# Design System Changelog

Newest first. Written by `/evolve`. Format per change: `property: old -> new (why)`.

## 0.1.0 - 2026-10-17

Seed. Source: user dictation in the setup session, not an episode.

- Captions: keyword emphasis, fade plus slide up.
- Motion: ease in and out everywhere. Entrances: fade+slide up/down, fade+blur+slide.
- Camera: punch-in and punch-out zooms. Up to two angles. J cuts and L cuts.
- Banned: strobe, flicker, Sapphire-style glow, shake.
- Feel: clean, minimal, high production quality.
